## What is this repository
This repository is collection of all my solutions to tasks on site [Frontend Mentor](https://www.frontendmentor.io/).
It includes both easy tasks from begginer categories and those that are more complicated (from junior categories).

## How to acces the tasks
The code for a specific task can be found in the folder named after the task (usually the same name as taks, but sometimes some small changes could have benn made).
The preview for any task is on the live hosted gitpage in which you will be able to preview any of the solved tasks. You can acces the gitpage through the deployments section or by clicking [this](https://mermodev.github.io/Frontend_mentor/).
